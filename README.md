# مكتبة البرومتات العربية

هذا المستودع يحتوي على صفحة ويب ثابتة تقدم مجموعة من البرومتات العربية الجاهزة للاستخدام مع أدوات الذكاء الاصطناعي التوليدي. تم تحديث التصميم ليكون عصريًا بحركات خفيفة، ويعرض أقسامًا واضحة وبطاقات برومتات متخصصة في مجالات متعددة.

## محتويات الموقع
- ترويسة متدرجة الألوان مع مربّع بحث زجاجي ونافذة تعريفية عائمة تعرض فوائد المكتبة.
- قائمة تنقل سريعة تقودك إلى الأقسام الرئيسية: الكتابة، التسويق، البرمجة، التعليم، والتصميم.
- بطاقات برومتات مختارة مع وصف مختصر، وسياق الاستخدام، وشارات تصنيفية توضح مستوى الجهد المطلوب.
- قسم إرشادي من أربع خطوات لاستخدام البرومتات بكفاءة، بالإضافة إلى دعوة لاستقبال التحديثات عبر البريد.
- لمسات حركية ناعمة عبر دوائر متحركة وتدرجات حية تمنح الموقع طابعًا حديثًا مع الحفاظ على بساطته.

## كيفية الاستخدام
1. افتح الملف `index.html` في متصفحك المفضل عن طريق النقر المزدوج عليه أو تشغيل أمر `xdg-open index.html` (لينكس) أو `open index.html` (ماك).
2. استخدم مربع البحث أو الأقسام المختلفة لاستكشاف البرومتات.
3. انسخ البرومت المناسب وعدله بحسب احتياجاتك قبل إدخاله في أداة الذكاء الاصطناعي.

## الملف والرابط النهائي
- الملف النهائي للموقع: [`index.html`](index.html)
- يمكنك مشاركة الموقع عن طريق رفع الملف إلى أي استضافة ثابتة (مثل GitHub Pages أو Netlify) ثم مشاركة الرابط الناتج. زر الدعوة في الصفحة يستخدم بريد `hello@example.com` ويمكنك تحديثه ببريدك الخاص لتوليد رابط التواصل النهائي مع الزوار.

## المساهمة
- يمكنك اقتراح برومتات جديدة أو تحسين النصوص الحالية من خلال فتح تذكرة (Issue) أو إرسال طلب دمج (Pull Request).
- عند إضافة برومت جديد، حاول توفير السياق، الهدف، وأي متطلبات خاصة تساعد المستخدمين الآخرين على تحقيق أفضل النتائج.

## الترخيص
هذا المشروع متاح للاستخدام الشخصي والتعليمي. يرجى الإشارة إلى المصدر عند إعادة نشر المحتوى أو مشاركته.
