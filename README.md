# مكتبة البرومتات العربية

هذا المستودع يحتوي على صفحة ويب ثابتة تقدم مجموعة من البرومتات العربية الجاهزة للاستخدام مع أدوات الذكاء الاصطناعي التوليدي. تم تصميم الصفحة لتكون سهلة التصفح، وتعرض أقسامًا واضحة وبطاقات برومتات متخصصة في مجالات متعددة.

## محتويات الموقع
- ترويسة جذابة مع مربع بحث زجاجي يسهّل الوصول إلى البرومت المطلوب.
- أقسام رئيسية تشمل الكتابة، التسويق، البرمجة، التعليم، والتصميم.
- بطاقات برومتات مختارة مع وصف مختصر، وسياق الاستخدام، وشارات تصنيفية.
- قسم نصائح عملي لمساعدة المستخدم على تحسين نتائجه مع النماذج التوليدية.

## كيفية الاستخدام
1. افتح الملف `index.html` في متصفحك المفضل عن طريق النقر المزدوج عليه أو تشغيل أمر `xdg-open index.html` (لينكس) أو `open index.html` (ماك).
2. استخدم مربع البحث أو الأقسام المختلفة لاستكشاف البرومتات.
3. انسخ البرومت المناسب وعدله بحسب احتياجاتك قبل إدخاله في أداة الذكاء الاصطناعي.

## المساهمة
- يمكنك اقتراح برومتات جديدة أو تحسين النصوص الحالية من خلال فتح تذكرة (Issue) أو إرسال طلب دمج (Pull Request).
- عند إضافة برومت جديد، حاول توفير السياق، الهدف، وأي متطلبات خاصة تساعد المستخدمين الآخرين على تحقيق أفضل النتائج.

## الترخيص
هذا المشروع متاح للاستخدام الشخصي والتعليمي. يرجى الإشارة إلى المصدر عند إعادة نشر المحتوى أو مشاركته.
